For `.py` files the symbol is a `def`, `class`, module constant or dict key; for `.rs` files a `fn`, `struct`, `enum`, `const` or `type`; for `PG_TOSS_CARD_PROFILE.md` exact text present in the file. Enum variants are cited through the enum definition and named in the free text. The owner cell lists `;`-separated owners; every owner is written verbatim in the contract except the reserved literal `k-stage5-durable-tx`, whose record is not on this base.
