Free text in a cell uses no backticks — every backticked path::symbol span in this document is checked: the path must be repo-relative, exist, never lie under `reference/v0.3-rc1/`, and the symbol must exist in the file (a `#[test]` `fn` for test files, a `pub` definition for `lib.rs`, verbatim text for Markdown).
