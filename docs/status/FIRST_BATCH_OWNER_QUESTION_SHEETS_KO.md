## 회신과 기록 방법

각 질문은 질문 번호와 요청한 항목을 적어 한 번에 답할 수 있다. 모르는 항목은
`미확인 / 확인 담당자 / 필요한 자료`로, 제공하지 못하는 자료나 보장하지 않는 사항은
그대로 표시해 달라. 답변을 추정하거나 공란을 무제한·허용으로 해석하지 않는다.
공통 회신 형식: `질문 번호 / 답변 / 적용 범위·버전 / 근거 자료 위치·작성일 / 회신자·역할`.

각 표의 **기록 위치**는 회신 후 별도 검토를 거쳐 반영할 기존 정본의 위치다.
회신 원문은 접근이 통제된 증거 보관 위치에 두고, 정본에는 비밀을 제외한 요약과
원문 참조·출처·회신일·적용 범위를 남긴다. 비밀 API 키, 카드번호, CVC, OTP,
개인정보 원문은 이 질문서·Git·채팅에 넣지 말고 기존 승인된 보안 경로의 참조만 제공해 달라.
보관 위치나 권한이 정해지지 않았다면 미확인으로 남긴다.

제공자·법무 답변이 필요한 값은 `UNDETERMINED`와 담당자를 유지한다.
제품 정책 수치와 새 프로토콜 명령은 `DECISION_REQUIRED · Astra` 검토 및 필요한
사용자 결정으로 이어진다. 회신만으로 입력 행을 완료 처리하거나 구현·실운영을 승인하지 않는다.
[STATE_LIFECYCLE](../contracts/STATE_LIFECYCLE.md) 초안 0.6과
[프로그램 결정 §5](../decisions/PROGRAM_DECISIONS_20260928.md)의 잠금·해제 조건은 유지한다.
