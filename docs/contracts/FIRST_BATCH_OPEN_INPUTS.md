## 1. 미정 입력과 답할 주체


| 입력 | 상태 | 사용자가 정하거나 제공할 것 | 조사/외부 확인으로 답할 것 | 확정 책임 |
|---|---|---|---|---|
| 대상 provider/account/API/product | 미정 | 실제 채택 후보·계약 계정·시험/운영 범위 및 비공개 자료 접근 | 공개 API·sandbox 자료의 지원 범위 | 사업 책임자(사용자) + PG 계약 담당 |

| 클라이언트 재시도 지원기간·메모리 보관량·SLO | 미정 | 사업상 지원·비용·실패 허용 정책을 선택 | 트래픽·장비·과거 사건을 측정해 선택 근거 제공 | 사업 책임자(사용자) 승인 |

| final 판정·review 해제·증거 회수 승인 주체 | 미정 | 담당 인간/법인·권한 분리·대체 담당자 지명 | 최소권한·감사 경로를 계약으로 표현 | 사용자/운영 책임자; 실제 담당자 아직 미지정 |
| C_g/H_g·이전 writer 차단·미발행 약정의 독립 증명 | 미정 | 신뢰/비협조 시 정지 정책·외부 보관 주체 수용 범위 결정 | 프로토콜 연구·위협 분석·독립 검토로 증명 가능한 관계 제시 | 프로토콜 개발/독립 검토 후 사용자 승인; 현재 증명 없음 |
| 원문 보존 확인·보관자 가용성·증거 재조회 | 미정 | 데이터 접근·보관 예산·운영 책임 배정 | 후보 보관 서비스/계약/가용성 근거 확인 | 운영/보안 책임자; backend 착수는 별도 |

사용자에게 PG의 물리적 최종성이나 암호학적 cut 증명을 추측해 달라고 요구하지
않는다. 사용자는 사업 선택·권한과 실제 계약 접근을 정한다. 공개 조사로 확정할
수 없는 계정별 조건은 provider 서면 답변이 필요하다. source cut은 문서 검색만으로
완성되는 제품 파라미터가 아니라 설계·독립 검증이 필요한 미해결 기술 관계다.
LC-FACT/LC-CUT/LC-TERM의 출처와 (a) 재사용 원칙은 유지한다.

## 2. 소진과 잔여 — 실측 공수와 계획 환산 구분

인간 작업시간표가 없어 실제 소진 인일은 **모름 / 숫자 없음**이다. AI 응답시간·CI
시간을 인간 개발일로 바꾸지 않는다. 다음은 1인8시간의 작업분해에 따른 계획용
