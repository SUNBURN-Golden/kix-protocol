## 1. Vocabulary

| Status | Rule used here |
|---|---|
| `COVERED_LOCALNET` | A Move, Python or Rust citation, and a localnet script, vector or validation-record citation. |
| `COVERED_MODEL_OR_MEMORY` | A Move (`test_scenario`), Python model or Rust in-memory citation; no localnet citation is needed. |
| `PARTIAL` | At least one citation, and a sentence naming what is missing. |
| `NOT_COVERED` | No citation in any layer. No row has this status at this base. |
| `MEASUREMENT_ONLY` | The profile hands the remaining obligation to RS-4 measurement; the structure half is cited and no figure is claimed. |

A row takes the weakest status of its halves: (a)/(b) for RS-C03, RS-C06 and RS-C07, public/private/delegated for RS-C14. Citations are `path::symbol`. Layer cells: Move test, Python model test, Rust in-memory test, localnet script or validation record. `none` means the layer cites nothing. Localnet counts such as `PASSED_ACTUAL_LOCALNET` live in the cited records at their own heads and were not re-run for this map. For the `.md`, `.json` and `.mjs` sources the symbol is a text string present in the file, so a record citation points to a sentence of that record and not to a re-run.
