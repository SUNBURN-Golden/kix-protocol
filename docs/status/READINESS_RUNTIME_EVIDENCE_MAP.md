## 1. Vocabulary

| Status | Rule used here |
|---|---|
| `EXERCISED` | At least one fixture citation in the four fixture columns, and the missing cell is `none`. |
| `PARTIAL` | At least one fixture citation, and a sentence naming what is missing, with an owner. |
| `NOT_EXERCISED` | No fixture column cites anything; the gap is named, with an owner. No row has this status at this base. |
| `OPEN` | A deferred or held item the contract itself leaves open — the three class-B characterizations pending the Astra ruling on the contract's recovery clause and the six `보류` items. Only the designated OPEN-* and HOLD-* rows may carry it; the map never reclassifies one. |

Cell grammar per fixture column and the impl/record column: `none`, or one or more `path::symbol` citations with optional free text (free text uses no backticks — every backticked span is parsed as a citation). For `.py` files the symbol is a `def`, `class`, module constant or dict key; for `.md` files exact text present in the file. The missing-or-open cell is plain text only — it never carries a citation. The owner cell is `none` or `;`-separated owners; every owner is written verbatim in the contract, `readiness/CONFORMANCE.md` or `docs/decisions/PROGRAM_DECISIONS_20260928.md`, except the reserved literal `DECISION_REQUIRED · Astra`.
