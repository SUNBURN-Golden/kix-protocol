# KIX 후속 개발 계획

갱신일: 2026-09-13. 현재 기준은 **v0.3-rc1 + ZK 설정·권리 현재성 보완**이다. 과거 계획은 [v0.1 원문](ROADMAP-v0.1.md)과 Git 이력에 보존했다.

원래 목표는 예매·공식 리셀·이해관계자 배분·정산·금융 근거·마케팅 동의를 연결하면서, 사업자 간 권리 검증과 필요한 정보의 비공개 처리를 가능하게 하는 것이다.

## 완료 범위

Python 합성 모형은 상충 환불·정산 집계·부분 지급과 반환·영속 송신·재고 식별자·예약 규칙을 보충한 rc1이며 이번에 88개 검사를 재실행했다. 기존 선택 변이 14개는 원래 rc1 결과로 보존했다.

Sui·SDK 설치와 버전 고정, Move 검사 3개, Node 오프라인 검사 4개, 회로 2개 컴파일, 공개·비공개 로컬넷 여정을 완료했다. 별도 프로세스 복구·실제 Groth16 수락·문맥 및 검증키 불일치·중복 사용 거절의 영수증을 확보했다. 이후 회로별 기여 누락을 재현·수정하고, 실제 체인에서 조작 증명·폐기·세대 변경·공연 취소 거절과 유효 노트의 증명 갱신을 확인했다. [보완 결과](PROTOCOL_HARDENING.md)를 따른다.

## 다음 구현과 완료 기준

| 우선순위 | 작업 | 완료 증거 |
|---|---|---|
| 1 | 권리·거래·정산의 실제 어댑터 통합 | [통합 계약](PROTOCOL_INTEGRATION_NEXT.md)의 유상 거래·외부 결과 관측·장애 복구를 동일 거래 근거로 연결 |
| 2 | PG·Sui 어댑터와 지급/환불 대사 | 실제 PG 시험 응답, 체인 확정, 타임아웃·중복·늦은 응답·사후 반환의 원자료와 상태 연결 |
| 3 | 리셀·배분·제품 정책 | 다수 수취인, 차익/총액, 반올림, 비용·환불 부담을 고정한 정책 버전과 대조 결과 |
| 4 | 비공개 리셀·환불·복구 | 거래 시 필요한 자격·현재성·금액 검증과 권리 회수, 부분 공개 범위 및 키 교체의 구현·실패 사례 |
| 5 | 복수 운영자의 권리 상호운용 | 승인 물량과 원 발권의 폐기·전환 증거, 사업자별 권한, 동시 유효 방지 및 별도 운영자 복구 |
| 6 | 독립성·분산 장애 조건 확장 | RPC 대체, 검증된 체크포인트, 복수 검증자 장애 조건, 백업·가스·검표 권한 의존성의 명시적 검사 |
| 7 | 금융 자료·마케팅의 제품 연결 | 판매·배분·미확정 환불 부담의 구분, 기준 시점·증거 범위, 실제 발송 직전 동의 확인 |

현재 Move 공연 정원과 비공개 모형은 모두 최대 16슬롯이고 전환 거래와 주소가 공개된다. 운영용 신뢰 설정과 회로 감사가 남아 있다. 아직 없는 로그인·salt·대납 서비스를 중지했다고 표현하지 않는다. 체인·PG 변경을 하나의 SQLite 트랜잭션으로 취급하지 않는다.

특허 관련 기록에는 인간의 기술적 선택·발명 기여와 선행기술 대비를 계속 남긴다. 실제 실행 성공만으로 신규성·진보성을 확정하지 않는다. 상세 실행 근거는 [실행 검증 보고](RUNTIME_VALIDATION.md), 설계 근거는 [Sui·ZK 설계](../reference/v0.3-rc1/DESIGN_SUI_ZK.md), 경계 사례는 [v0.2 검토](../reviews/v0.2-2026-09-11/KIX_v0.2_목적대조_기술검토.md)를 따른다.
