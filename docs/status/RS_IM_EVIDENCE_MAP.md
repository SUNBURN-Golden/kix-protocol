## 1. Vocabulary

| Status | Rule used here |
|---|---|
| `COVERED_LOCALNET` | A Move, Python or Rust citation, and a localnet script, vector or validation-record citation. |
| `COVERED_MODEL_OR_MEMORY` | A Move (`test_scenario`), Python model or Rust in-memory citation; no localnet citation is needed. |
| `PARTIAL` | At least one citation, and a sentence naming what is missing, with an owner. |
| `NOT_COVERED` | No citation in any layer. No row has this status at this base. |
| `MEASUREMENT_ONLY` | The profile hands the remaining obligation to RS-4 measurement. No row has this status at this base. |
| `UNCHANGED_BY_DESIGN` | Only for a row whose treatment is 손대지 않음 (untouched), when the untouched claim is the whole executable content; an unchanged-file citation is required. Rows with 유지 (keep) take the ordinary statuses. |

Treatment words: 유지 keep, 변경 change, 새 프로파일 new profile, 손대지 않음 untouched.

A row takes the weakest status of its halves. Citations are `path::symbol`. Layer cells: Move test, Python model test, Rust test (`kix-delegated-exec`, `kix-kernel-v5`), localnet script or validation record, unchanged-file evidence (locked kernel constants and tests, the mock gates, contract and historical documents, the workflow). `none` means the layer cites nothing. For the `.md`, `.json`, `.mjs` and `.yml` sources the symbol is a text string present in the file, so a record citation points to a sentence of that record and not to a re-run. For a `.test.mjs` source the symbol is a node:test name, located as `test('name'` or `test("name"` in the file; the checker proves the name exists, not that the test asserts the sentence or passes. Localnet results such as `PASSED_ACTUAL_LOCALNET` live in the cited records at their own heads and were not re-run for this map.

Owner cell: required for `PARTIAL`, `NOT_COVERED` and `MEASUREMENT_ONLY` rows. The impact table has no owner column, so an owner is written in the profile's own words: a node the policy sentence names (IM-16 and IM-27 RS-2, IM-26 `RS-3b와 Track K v5`), the owner cell of the RR or section 4 row the sentence points to (IM-10 section 9, IM-29 section 6, IM-17 and IM-11 section 4 ceiling 5), or the reserved literal `none stated in profile`, which the record lists as a class B item.
