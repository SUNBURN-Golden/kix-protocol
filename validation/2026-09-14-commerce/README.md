## 주요 근거

- 60,000원 묶음에 정액 6,000원과 이후 10% 할인을 적용한 고객 부담은 48,600원이다.
- 두 번째 주문행 반환안은 카드 10,000원 + 계좌 6,200원이며 할인 부담 취소분 3,800원을 별도로 계산한다.
- 0/2/6/18자리 자산에서 2^53을 넘는 금액이 문자열·소수 표현으로 정확히 왕복한다.
- 잘못된 자산·합계·만료·중복 행·과도한 할인·조작된 계산·허용하지 않은 실행 동작을 거절한다.
- 늦은 공연 취소·송신 후 상충 증거·설치 직전 변경에 대한 HOLD 근거가 보존된다.
- 감사 기록 전후 종료, 쓰기 실패, 기존 기록 훼손, rename 이후 디렉터리 동기화 실패와 재시도를 검사한다. 예약·pending·의무는 유지한다.
- S05의 원 폴더 삭제·읽기 전용 복원·archive 최신 기록 비교 검사는 전체 회귀 검사에 포함한다.

## 근거의 한계와 CI

`commerce.json`은 **CALCULATION_ONLY**다. 실제 결제 승인·환불·할인 채권·발권 실패·언어 모델 실행을 재현한 자료가 아니다. 복구 검사는 모의 PG/은행과 합성 체인 조회를 사용한다. 보류 감사 파일은 로컬 자료이며 독립 보존 전체를 검증하지 않았다. 과거 자연 유실 원인과 G0 전체 완료는 남아 있다.

이 변경의 GitHub 자동검사는 Python·SDK·Move·회로·기존 실제 Sui 공개/유상/비공개 여정 및 ZK 조작 거절을 유지하며 계산 계약 재현을 추가한다. 로컬에서 직접 실행한 Python 결과와 실제 체인·ZK의 CI 결과를 구분한다. CI 결론과 실행 링크는 해당 PR의 현재 head에 연결해 기록하며, 이 파일을 작성한 시점의 로컬 성공을 CI 성공으로 대신하지 않는다.

기존 S05의 [CI 34814252032](https://github.com/BeautifulMind-JT/kix-protocol/actions/runs/34814252032) 성공은 기준 소스의 근거다. S06의 CI를 대신하지 않는다. 이 변경의 실제 Sui 유상 시나리오도 자금 제공자는 모의 구현이다.
