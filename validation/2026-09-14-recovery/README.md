# S03 복구 검증 근거

기준 커밋은 PR #3의 `c512171`이다. 이번 자료는 과거 자연 유실의 원인 재현이 아니다.

- `python-default.log`: Python 3.12.14 / SQLite 3.53.1, 전체 123개 검사 통과.
- `python-system.log`: Python 3.12.3 / SQLite 3.45.1, 전체 123개 검사 통과.
- `paid-recovery.json`: 원 요청 → 제공자 조회 → 합성 체인 근거 → 복구 결정 → 복구 결과 → 후속 출금 관측 및 잔여 의무를 묶은 두 사례. 반복 복구의 장부 무변경과 제공자의 경제적 실행 1회를 확인한다.
- `manifest.json`: 변경 소스와 결과의 SHA-256. JSON의 실행별 계획 ID는 조회 시점·일회용 작업 경로에 결합되어 재실행마다 달라질 수 있다.

두 최초 중단점 각각에 대해 복구 자체를 여섯 위치에서 재종료하는 12개 조합을 새 검사에 포함한다. 후보 장부에 상태를 반영하다 종료하는 경우도 포함된다. 테스트 프로그램만 장애 위치를 알며 복구 함수에는 그 정보를 전달하지 않는다.

여기 보존한 두 보고서 사례의 체인 근거는 **합성**, 돈은 **모의**다. 실제 Sui 로컬넷의 두 복구 사례는 `localnet-paid.mjs`와 해당 커밋의 CI에서 별도로 확인한다. CI 산출물은 원 실행의 GitHub Actions에 보존하며 로컬 결과로 바꾸어 표시하지 않는다.

과거 유실 원인, 독립 실패 영역의 저장·백업, 전체 생애주기, 실제 PG 운영 검증은 미완료다. 실제 운영 자료·키·서명·DB 사본은 이 배포 자료에 포함하지 않는다.
