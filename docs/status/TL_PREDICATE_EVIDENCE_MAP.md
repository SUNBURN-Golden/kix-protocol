## 3. Reconciliation with TL-4

- TL-4 §5 lists only `reference/v0.3-rc1/sui/Move.toml` as the locked manifest, while the current repository boundary test (`test_tl4_fuzz_boundaries.py::test_TL4_TK02_T1_only_the_authorized_move_manifests_exist`) also expects `reference/rights_scale/sui/Move.toml`. The map treats the TL-4 record's manifest count as stale and does not edit the record or the capability register.
- TL-4 §5 marks TK-10 and TK-11 as `REVIEWED (gate records)` / `REVIEWED (wording)`. The map keeps the same status but notes these are builder-side reviews, not an independent PASS.
- TL-4 §5 marks TK-9 as a name scan. The map keeps it as `PARTIAL` because the scan is not a proof that a gas-payment path is absent.
- TL-4 §6.A states that the author-side oracle matched the model; the map does not treat that as independent verification and keeps the operational count at 0.

- Independent review, Astra architecture audit, or operational readiness.

- Any policy value for supply cap, pool balance, collateral ratio, vesting schedule, approver set, token name/symbol, or price source.
