## 1. Vocabulary

Statuses describe only the clause slice stated in each row and finite, in-memory existing evidence. They do not change capability grades. COVERED means sufficiently covered for that slice; PARTIAL means partially covered; NOT_COVERED and OPEN mean no test is cited for that requirement.

| Status | Cell rule |
|---|---|
| COVERED | At least one contract-path test; Gap and Owner both none. |
| PARTIAL | At least one test in either column; named non-none gap and owner. |
| NOT_COVERED | Both test columns none; named non-none gap and owner. |
| OPEN | Both test columns none; gap names I09–I13, UNDETERMINED or DECISION_REQUIRED; named owner. L4-HANDOFF always OPEN with I12 as owner. |

Test cells are literal `none` or comma-separated backticked repo-relative path::symbol citations to existing #[test] fns. Bare paths, empty symbols, helpers, prose mixed into citation lists and reference/v0.3-rc1 citations are rejected. Contract-path tests use only the four allowed v4 example/invariant files and v5 test files other than the two model suites. Source-informed tests use only v4 e4_state_model.rs and v5 lifecycle_model.rs/v4_differential.rs. The split describes the oracle path, not clean-room authorship: even contract-path authors knew kernel source ([CONTRACT_INVARIANTS §1](../contracts/CONTRACT_INVARIANTS.md#1-provenance-correction--not-a-clean-room-reference)).

INV cells are `none` or comma-separated INV-1 through INV-5. Each non-none INV cell also cites the existing kernel-only generated-history test in the contract-path column; this links the predicate evidence without claiming it tests every detail of the row. Gap/Owner are nonempty free text without backticks; every I-number must exist in the open-input table. E4's altered-payload-matrix citation tests evidence-gate classification only; its exact-read-only citation tests sensitivity to an extra public clock-advancing call. Neither is an additional direct proof of kernel semantics. V5 model agreement likewise is not an independence proof.
