# KIX 후속 개발 계획

갱신일: 2026-09-11. 현재 기준은 [v0.3-rc1](../reference/v0.3-rc1/README.md)이다. 과거 v0.1 계획은 [원문](ROADMAP-v0.1.md)에 보존했다.

## 완료 범위

Python 합성 기준 모형에서 상충하는 환불 증거의 예약 해제 차단, 경제적 사실의 해결·반영 상태 연결, 부분 실행의 최종 종료와 반환, 영속 요청과 작업자 인수, 증거 요약, 재고 식별자 충돌, 결제 예약 시간 상한을 보충했다. 검사 88개와 선택한 변이 14개로 확인했다. 이는 실제 PG나 체인의 동작 검증을 뜻하지 않는다.

Sui 권리 프로그램, 독립 클라이언트, 암호화 백업과 ZK 회로를 작성했다. 백업·직렬화의 Node 오프라인 검사 4개는 통과했으나 Move 컴파일, 실제 체인 여정, 증명 생성·체인 검증은 미완료다.

## 다음 실행 기준

| 순서 | 작업 | 완료 증거 |
|---|---|---|
| 1 | Sui CLI·SDK·회로 도구 설치와 버전 고정 | 실제 버전, 의존성 잠금 파일, Move 빌드·테스트 로그 |
| 2 | 공개 권리의 운영자 독립 여정 | A→B 이전 후 별도 프로세스에서 B의 백업 복구·권한 있는 다른 검표자의 1회 소비, A와 재사용 거절의 체인 영수증 |
| 3 | 같은 권리의 비공개 검표 | 회로·검증키 고정, 실제 증명 생성·검증, 현재 세대·문맥·검증키·중복 소비에 대한 거절 영수증 |
| 4 | 리셀·환불·배분의 외부 증거 연결 | 결제 증거 발급자 계약, 원자료·정산 대사, 체인 성공/실패/조회 불명확 상태의 실제 어댑터 처리 |
| 5 | 제품별 정책과 상호운용 확장 | 다수 수취인·차익/총액·반올림·취소 부담 정책, 원 티켓과 새 권리의 동시 유효 방지 |

첫 체인 검증의 설정 프로세스는 실제 KIX 운영 서비스가 아니다. 없는 로그인·salt·대납 서비스를 중지했다고 표현하지 않는다. 복구 자료·가스·RPC·검표 권한의 의존성을 각각 기록한다.

현재 비공개 후보는 최대 16개 재고·노트이며, 비공개 전환 후 검표와 발행 권한자의 폐기/공연 취소만 다룬다. 비공개 리셀·환불·재발행·키 교체는 후속 구현이다. 단일 주체 시험용 ZK 설정을 운영용 설정으로 취급하지 않는다.
