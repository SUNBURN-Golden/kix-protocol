  CONTRACT_INVARIANTS `F-B*` findings cite the evidence map that defines those ids.
  A later restatement of the same item gets no row.
- **Quote**: an excerpt copied byte-for-byte from one line of the source. It is not a
  restatement of the item and does not carry its whole text.
- **Test**: the tests the source names for the item, as `path::symbol`.

  means the source names a glob family or a symbol that is not defined in the tree.
- **Contract / clause** and **Owner**: verbatim from the source, or `not named in source`.
- **Status**: `none` means no later merged record in the scanned set says the item is
  superseded. A superseded row reads ``superseded by #NNN: `<record>` "<quote>"``.
