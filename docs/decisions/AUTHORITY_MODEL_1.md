## 권위 모델

모델 1 — 체인 권위 / 오프체인 위임 실행을 단일 선택으로 고정한다.
재고 원권위와 관람권의 발행/소유/이전/소비 권위는 체인에 둔다.
오프체인 실행자는 검증된 배타 범위 안에서 예약·판매 약정을 처리한다.
`예약 확정 ≠ 결제 확인 ≠ 체인 권리 발행 완료`다. 실제 은행 자금·계약상
채무·공연 이행을 체인이 자동 보증하지 않는다. 특정 backend를 채택하지 않는다.
R1 v4는 세 모델 중 어느 것도 완전 구현하지 않는다. 현재 local generation은
chain lease generation이 아니며 replace_owner는 실제 fencing/상태이관이 아니다.

## 승인된 A-4 — 기록과 재생의 필수 분리

| 사실 | 보존할 내용 | 별도로 둬야 하는 경계 |
|---|---|---|
| grant | chain/network/package·grant id/version·원재고·범위/수량·수임자·허용 동작·lease generation | execution generation·업무 epoch와 동일시 금지 |
| 유효기간/현재성 | 시작/만료·시간원·확정 증거·관측 기준 | 예약 TTL과 lease 만료는 다름 |
| 회수 | 요청/체인 확정, 영향 generation, 신규 약정 중단 cut C_g, 체인 경계 H_g | 로컬 cancel/owner 변경이 체인 회수 완료는 아님 |
| 기존 소비·미발행 | command·최초 결과·source position·사용 재고·지급/발행 대기·반환 의무·증거 | 침묵/timeout으로 미사용이라 간주 금지 |
| 체인 사실 | tx/effects·검증 결과·Right id/version과 원예약/지급/grant 결합 | local sync/sequence를 chain finality로 대체 금지 |
| 내구성 | 오프체인 커밋 위치와 체인 확정 위치를 각각 보존 | 같은 물리 로그여도 권위와 커밋은 합쳐지지 않음 |
| 복원/재실행 | wire/semantics·역사 입력·회수 cut·현재 권한 재검증 | 과거 사실 재생은 새로운 외부 실행 허가가 아님 |

회수 cut 이후 옛 generation으로 새 재고를 소비하거나 새 외부 실행을 허가하지
않는다. 로그를 그 지점에서 잘라 늦은 capture·체인 결과·반환 의무를 버리는 것은
금지한다. 과거에 유효했던 약정은 당시 의미와 증거로 복원하고, 늦은 사실은 현재
권한으로 대사한다. cut을 증명하지 못하면 영향을 받는 새 소비·재위임을 보류한다.
완전한 비협조 증명, 독립 이력 가용성, 현재성 시간원/수치는 아직 미정이다.
